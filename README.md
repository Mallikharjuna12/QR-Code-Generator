# 🔳 QR Code Generator

A modern and responsive QR Code Generator built using **HTML**, **CSS**, and **JavaScript**. Users can instantly generate QR codes for text, URLs, or any other input and download the generated QR code image.

## 🚀 Features

- 🔳 Generate QR codes instantly
- 🌐 Supports text and website URLs
- ⬇️ Download generated QR code
- ⌨️ Press **Enter** to generate
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- ✅ Beginner-friendly project

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

```
QR-Code-Generator/

```

---

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter any text or URL.
5. Click **Generate QR Code** or press **Enter**.
6. Download the generated QR code.
